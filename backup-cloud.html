Ein Backup ist nur gut, wenn die Wiederherstellung klappt

Ein defekter Laptop, ein versehentlich gelöschter Ordner oder ein Verschlüsselungstrojaner – ohne funktionierende Datensicherung kann ein einziger Tag die Arbeit von Jahren kosten. Viele Betriebe glauben, ein Backup zu haben, und merken erst im Ernstfall, dass es seit Monaten nicht mehr läuft.

Wir richten Ihre Datensicherung so ein, dass sie automatisch läuft, überwacht wird und im Notfall wirklich hilft. Dabei folgen wir der bewährten 3-2-1-Regel: drei Kopien Ihrer Daten, auf zwei verschiedenen Speichern, davon eine außer Haus.

Daran erkennen Sie Handlungsbedarf

  • Gesichert wird nur auf eine externe Festplatte, die immer angesteckt ist
  • Niemand prüft, ob die Sicherung wirklich erfolgreich war
  • Microsoft 365 oder E-Mails werden gar nicht gesichert
  • Eine Wiederherstellung wurde noch nie getestet
  • Sie wissen nicht, wie lange Sie im Notfall ohne Daten wären

Häufige Fragen

Was ist die 3-2-1-Backup-Regel?

Sie bedeutet: drei Kopien Ihrer Daten, auf zwei unterschiedlichen Speichermedien, und eine Kopie an einem anderen Ort, zum Beispiel in der Cloud. So sind Ihre Daten auch bei Brand, Diebstahl oder Ransomware geschützt.

Reicht eine externe Festplatte als Backup?

Als alleinige Lösung nicht. Ist sie dauerhaft angeschlossen, kann sie bei einem Angriff mit verschlüsselt werden. Und bei Brand oder Diebstahl ist sie zusammen mit dem Computer weg.

Muss ich Microsoft 365 extra sichern?

Wir empfehlen es. Microsoft schützt vor eigenen Ausfällen, aber gelöschte oder verschlüsselte Daten lassen sich ohne eigenes Backup oft nur kurze Zeit oder gar nicht zurückholen.

Wie oft sollte gesichert werden?

Für die meisten Betriebe ist eine tägliche automatische Sicherung sinnvoll. Wichtige Daten, die sich ständig ändern, können auch mehrmals täglich gesichert werden.
